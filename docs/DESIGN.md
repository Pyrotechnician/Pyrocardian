# 卡迪安（Cardian）设计文档

## 世界观

- 卡迪安世界原本是一副无限的卡堆，创世者每翻开一张卡，世界就展开一片。
- 打开网站并登录 = 翻开自己的第一张卡，进入卡迪安世界。
- 首页是生活化的小镇广场：集市（熔炉：分解/合成）、竞技场（PvE/PvP）、图书馆（单词卡）、收藏馆（角色卡）、自宅（配卡组）。各地点是"场景卡"入口。
- 一切皆卡：角色卡、技能卡、单词卡、场景卡（以后可扩展事件卡、装扮卡）。

## 角色卡

- 全服唯一（1/1）：随机名字（地名前缀 + 人名）+ 职业；职业才是培养维度。
- 不可分解，可"退役"返还卡尘。
- 职业由数据文件定义（`content/cards/classes.json`），新增职业 = 新增一张角色卡配置，是后续扩展门路，旧卡永久有效。

## 职业（现阶段）

| 职业 | 可参战 | 定位 |
| --- | --- | --- |
| 异世界访客 | 是（仅普攻 + 通用技能卡） | 注册默认获得；生活/背单词入口 |
| 学者 | 否（功能性职业） | 唯一可在熔炉合成技能卡 |
| 召唤师 | 是 | 可使用召唤技能卡，召唤独立血量的召唤物（场上限 2） |
| 火/水/雷/冰/土魔法师 | 是 | 各系专属技能卡 + 元素附加效果（灼烧/治疗护盾/连锁/冻结/嘲讽），系间软克制 10-20% |

- 治疗位 MVP 由通用治疗卡承担；治疗/辅助职业（园丁、诗人等）留作后续角色卡扩展。

## 技能卡

- 消耗品：战斗中打出即永久消耗；来源 = PvE 掉落 + 学者合成。
- 分通用池与职业专属池；费用 1-5 法力；稀有度四档 common / rare / epic / legendary。

## 战斗系统（MVP：回合制 1v1 单角色）

- 角色 HP ~30 + 免费普攻；法力每回合 +1（上限 10），每回合抽 1 张，手牌上限 7；疲劳伤害递增保底。
- 卡组 = 角色卡 + 技能槽位（2-5 个，由稀有度决定），战斗开始时洗入手牌。
- 一局目标 10-15 回合（5-10 分钟）。
- PvE：章节关卡 + 周常 Boss，消耗真实技能卡，掉落卡尘/技能卡，首通奖励角色卡。
- PvP：好友房（创建/按房间号加入/快速匹配）+ 天梯赛季，幻影卡组不消耗。战斗服务端权威（Colyseus `battle` 房间：`apps/server/src/rooms/BattleRoom.ts`，状态定义在 `packages/shared/src/battle.ts`，前后端共用），以后可加异步防守阵容。
- 已实现：建房/加入、法力成长、抽牌/手牌上限、伤害/治疗/护盾/召唤、灼烧/冻结、元素软克制（×1.2）、普攻、疲劳、胜负判定与战斗日志。PvE 下一步用同一引擎接 AI 对手。

## 单词卡（生活线）

- 德语/英语单词卡 = "言灵卡"，在图书馆学习，SRS 间隔复习；奖励卡尘/装扮卡；可赠送好友。
- 不与战斗强绑定，是卡迪安生活的一部分。

## 卡图

- 卡图统一暖色奇幻 TCG 风格，由内置图像生成工具批量生成，存于 `content/assets/cards/<卡牌id>.jpg`；职业立绘为 `class_<职业id>.jpg`。
- 管线：生成结果写入 `/tmp/gen/<id>.json`，`node scripts/download-art.mjs` 下载入库（README 有说明）。

## 经济

- 卡尘 = 通用货币；分解（回炉）人人可做，合成（重铸）仅学者可做。

## 界面语言

- 中英双语 UI：自研轻量字典（`apps/web/src/i18n.ts`），默认跟随浏览器语言，广场右上角可切换。
- 卡牌 JSON 可选英文字段（`nameEn`/`descriptionEn`/`textEn`），缺省回退中文；服务端错误以错误码返回，客户端翻译。
- CI：GitHub Actions 跑 typecheck + build + 服务端冒烟测试（`scripts/smoke-test.mjs`）。

## 技术栈

- Monorepo（npm workspaces）：`apps/web`（Vite + React + TS）、`apps/server`（单个 Node 进程：Hono REST + Colyseus WebSocket 战斗房间 + 静态资源）、`packages/shared`（类型 + 卡牌 JSON 校验，前后端共用）、`packages/db`（better-sqlite3，SQLite 单文件 WAL）、`content`（卡牌 JSON + 卡图）。
- 认证：scrypt 密码哈希 + HMAC-SHA256 JWT，密钥在首次启动时生成并存于数据库 meta 表。
- 部署：单进程托管全部功能；备份 = 复制 `data/pyrocardian.db`。
