# 卡迪安（Cardian）设计文档

## 世界观

- 卡迪安世界原本是一副无限的卡堆，创世者每翻开一张卡，世界就展开一片。
- 打开网站并登录 = 翻开自己的第一张卡，进入卡迪安世界。
- 玩家是「异世界访客」，来到小镇，暂时在酒馆落脚。一切皆卡：角色卡、技能卡、单词卡、古老的卡牌、场景卡。

## 世界页面（小镇主街道）

- 登录即进入小镇：一张全景主街道背景 + 可点击建筑（场景卡）：竞技场 / 传送门 / 熔炉 / 酒馆 / 商店 / 图书馆。
- 酒馆 = 玩家仓库 + 背包（查看拥有的技能卡）+ 壁炉边背单词 + 亲和力加点 + 休息。
- 点击建筑切换到建筑内部背景 + 模块面板（带进入动画）；无 HUD，数值只在功能建筑内显示；语言切换放在登录页。
- 同时适配移动端与电脑端浏览器（响应式布局、大点击区域）。

## 角色卡：招募制（roguelite）

- 玩家不永久拥有角色卡。进入传送门时有招募环节：随机出现 3 张角色卡，选 1 张作为本次 PvE 的同伴。
- 角色死亡 → 玩家被传送回小镇，本次 PvE 失败（消耗的技能卡永久损失，返还少量魔晶石旅费）。
- 招募过的角色入图鉴（收藏/扩展门路）；新增职业 = 招募池扩展。
- 不同角色能使用的技能卡不同（职业专属池），部分角色对特定卡有额外加成。
- 亲和力（MMORPG 式加点）：访客升级获得亲和点，分配到五系；影响招募池中对应职业的出现权重，也在战斗中给对应元素加成。
- PvP 中玩家以「异世界访客」身份出战：可用任何技能卡，但没有任何特殊加成。

## 职业

| 职业 | 类型 | 定位 |
| --- | --- | --- |
| 异世界访客 | 玩家身份卡 | PvP 出战：任意技能卡，无加成 |
| 召唤师 / 火水雷冰土魔法师 | 可招募（PvE） | 召唤仆从 / 各系专属技能卡 + 元素效果，系间软克制 ×1.2 |
| 学者 | NPC（图书馆） | 鉴定古老的卡牌；相同卡牌生成制作秘方 |
| 铸造师 | NPC（熔炉） | 熔炼卡牌回魔晶石；秘方 + 原料铸造新卡 |
| boss 角色卡（哥布林王、雪山霜巨人…） | NPC boss，不可招募 | 传送门 PvE 的系统对手：高血量 + 召唤仆从 |

- 职业由数据文件定义（`content/cards/classes.json`，带 `npc` / `recruitable` / `boss` / `deck` / `hp` 标志）。

## 技能卡

- 消耗品：战斗中打出即永久消耗（PvE 真实库存；PvP 好友房幻影不消耗）。来源 = PvE 掉落 + 熔炉铸造 + 商店购买。
- 分通用池与职业专属池；费用 1-5 法力；稀有度四档 common / rare / epic / legendary。

## 战斗系统（回合制 1v1，服务端权威）

- 角色 HP ~30（boss 更高）+ 免费普攻；法力每回合 +1（上限 10），每回合抽 1 张，手牌上限 7；疲劳伤害递增保底。
- 一局目标 10-15 回合（5-10 分钟）。
- **PvE（第一期已实现）**：传送门选 boss → 招募 3 选 1 → 单挑 AI 控制的 boss 角色卡（会召唤哥布林等仆从）。胜：魔晶石 + 古老卡牌掉落 + 访客经验；败：回小镇 + 旅费。PvE 手牌存卡牌 instanceId，打出即从数据库删除。双人协作（2v1）放二期。
- **PvP**：好友房（创建 / 按房间号加入 / 快速匹配），幻影卡组不消耗。天梯（消耗卡，胜奖魔晶石+卡、负返 50%）放后续。
- 已实现：建房/加入、法力成长、抽牌/手牌上限、伤害/治疗/护盾/召唤、灼烧/冻结、元素软克制（×1.2）、普攻、疲劳、胜负判定、战斗日志、AI boss 回合。
- 引擎：Colyseus `battle` 房间（`apps/server/src/rooms/BattleRoom.ts`），状态 schema 在 `packages/shared/src/battle.ts`，前后端共用。

## 古老的卡牌

- PvE 掉落为主的未鉴定卡（kind: `ancient`），图书馆学者鉴定后随机替换成一张稀有度不低于原卡的可用技能卡。
- N 张同名卡可在图书馆生成制作秘方，拿到熔炉消耗原料（魔晶石为主）铸造指定卡。

## 单词卡（生活线）

- 德语/英语单词卡 = "言灵卡"，在酒馆壁炉边学习，SRS 间隔复习；奖励魔晶石/装扮卡；可赠送好友。
- 不与战斗强绑定，是卡迪安生活的一部分。

## 经济

- 魔晶石 = 通用货币（`users.magic_stones`）。熔炉熔炼回魔晶石；商店买卖基础技能卡；PvE 奖励；PvP 天梯结算。

## 卡图

- 卡图统一暖色奇幻 TCG 风格，由内置图像生成工具批量生成，存于 `content/assets/cards/<卡牌id>.jpg`；职业/boss 立绘为 `class_<职业id>.jpg`（boss id 形如 `boss_goblin_king`）。
- 管线：生成结果写入 `/tmp/gen/<id>.json`，`node scripts/download-art.mjs` 下载入库（已存在的自动跳过；README 有说明）。

## 界面语言

- 中英双语 UI：自研轻量字典（`apps/web/src/i18n.ts`），登录页切换并记住选择。
- 卡牌 JSON 可选英文字段（`nameEn`/`descriptionEn`/`textEn`），缺省回退中文；服务端错误以错误码返回，客户端翻译。
- CI：GitHub Actions 跑 typecheck + build + 冒烟测试（`scripts/smoke-test.mjs`）+ PvP 房间测试（`scripts/battle-test.mjs`）+ PvE 测试（`scripts/pve-test.mjs`）。

## 技术栈

- Monorepo（npm workspaces）：`apps/web`（Vite + React + TS）、`apps/server`（单个 Node 进程：Hono REST + Colyseus WebSocket 战斗房间 + 静态资源）、`packages/shared`（类型 + 卡牌 JSON 校验 + 战斗 schema，前后端共用）、`packages/db`（better-sqlite3，SQLite 单文件 WAL，手写迁移）、`content`（卡牌 JSON + 卡图）。
- 后端保持 Node（用 engines / .nvmrc / Dockerfile 锁定版本）；如未来需要单二进制再考虑 Rust 迁移（ws 消息保持简单 JSON，迁移门槛低）。
- 认证：scrypt 密码哈希 + HMAC-SHA256 JWT，密钥在首次启动时生成并存于数据库 meta 表。
- 部署：单进程托管全部功能；备份 = 复制 `data/pyrocardian.db`。
